# Security policy

**Sigil is not currently suitable for production authentication.** No Sigil verifier or server application has been implemented or independently reviewed in this checkout.

Do not rely on this repository to authenticate users. Do not submit seed phrases, private keys, session credentials, or sensitive proofs in public issues. Until a dedicated security contact is established, coordinate potential vulnerabilities with the project lead using a private channel.

Before production use, Sigil requires an independently verified server-side signature-validation path, strict statement parsing, atomic context-bound challenge consumption, secure session handling, a threat-model review, and independent security review.
